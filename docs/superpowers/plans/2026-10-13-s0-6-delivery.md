# S0-6 Delivery — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. In this workspace the implementer is the Opus `implementer` agent and the reviewer the Opus `code-reviewer` agent; Tasks 8 and 9 are run by the main session only. Agents never commit (memory `feedback-sdd-without-commits`).

**Goal:** A merge to `main` builds one Docker image, pushes it to ECR and rolls it out to staging on AWS by itself; production has the same deploy behind an approval. Staging answers on HTTPS behind a load balancer and a firewall, sends real emails, writes its logs to CloudWatch with saved queries and alarms, and passes the S0 definition of done (spec §11).

**Architecture:**
- **Image.** One multi-stage `Dockerfile`: Node 24 builds `admin-ui/`, the .NET SDK publishes `ExtraSpace.Api`, the ASP.NET runtime image runs it on port 8080 as a non-root user. The tag is the full commit SHA.
- **Infrastructure (CDK, `infra/ExtraSpace.Infra`).** Three new stack types next to `EsNetwork` and `EsData`:
  - `EsCi` (one, no environment): the GitHub OIDC provider, the ECR repository `extraspace/api`, and one deploy role per environment.
  - `EsEdge-<env>`: the HTTPS certificate and the SES email domain, with their DNS records in a hosted zone that client IT delegated to the account.
  - `EsApp-<env>`: load balancer, firewall (WAF), ECS cluster and services, task roles, the signing-key secret, log groups, saved log queries, metric filters, alarms, the DNS name.
- **Who changes what.** Infrastructure changes are `cdk deploy` runs by the owner, by hand. CI never runs CDK against AWS. CI only swaps the image: it registers a new task-definition revision with the new image, updates the ECS services, waits until they are stable, and then writes the tag to the SSM parameter `/es/<env>/app/image-tag`. The app stack reads the image tag from that parameter, so a later `cdk deploy` uses the image CI last rolled out.
- **Deploy values that must stay out of the public repo** (host name, zone id, email addresses) live in `docs/notes/infra/deploy-inputs/<env>.json` in the private context repo. The CDK app reads them from the folder named by `ES_DEPLOY_INPUTS`.
- **App (`src/ExtraSpace.Api`).** Four small changes so the image can run on AWS safely: the connection string is built from parts (the password comes from Secrets Manager), the app refuses to start when the database is behind the build, staging can only email an allow-list, and static text files are compressed.

**Tech Stack** (checked on 2026-10-13):

## Review Focus

1. **A deploy rolls back and CI still reports success.** ECS's circuit breaker puts the old tasks back, and `aws ecs wait services-stable` then succeeds. Expected: the deploy script compares the running task definition with the one it registered, fails the job, and does not record the tag. Pinned by Task 7 `deploy.sh` test case `rolled_back_deploy_fails_and_keeps_the_old_tag`.
2. **A build goes live before its migration was run.** Expected: the new task stops at start-up, the circuit breaker keeps the old version serving, the job fails. Pinned by Task 1 `A_build_ahead_of_the_database_refuses_to_start`.
3. **The task runs as `Development` or `Testing` on AWS.** The key ring would then sit in the database. Expected: `ASPNETCORE_ENVIRONMENT` is exactly `Staging` or `Production`. Pinned by Task 5 `Tasks_run_as_Staging_or_Production_only`.
4. **Something other than the load balancer reaches a task.** The app trusts `X-Forwarded-For` from any caller, so the per-IP limits would be forgeable. Expected: one ingress rule on the task security group, from the load balancer's group, port 8080; XFF mode `append`. Pinned by Task 5 `Only_the_load_balancer_reaches_the_tasks` and `Alb_appends_the_client_ip`.
5. **A staging test emails a real customer** once SES leaves the sandbox. Expected: staging refuses to compose without `emailAllowedRecipients`, and the job skips other addresses. Pinned by Task 3 `Staging_needs_an_email_allow_list` and Task 1 `A_recipient_off_the_allow_list_gets_nothing`.
6. **The staging deploy role can touch production.** Expected: each role is trusted only for its own GitHub environment and may update only its own cluster, pass only its own two task roles, and write only its own tag parameter. Pinned by Task 3 `Deploy_roles_are_scoped_to_their_environment`.
7. **A rate rule that upper-case paths walk around.** ASP.NET routes ignore case, WAF byte matches do not. Expected: the path match lower-cases first. Pinned by Task 6 `Auth_rate_rule_lowercases_the_path`.
8. **A production image disappears from ECR** after 30 newer staging builds, and the next scale-out cannot pull it. Expected: the production deploy adds a `prod-<sha>` tag and the lifecycle rule keeps those apart. Pinned by Task 3 `Production_images_are_kept_apart`.

## Decisions (to be approved by the owner; 3, 6 and 10 change the S0 spec)

1. **DNS: one delegated subdomain.** Client IT delegates one subdomain (example `app.<client domain>`) to a Route 53 hosted zone in the account (setup guide A8). Staging is `staging.<zone>`, production the zone itself. 🔴 `EsEdge-staging` and everything after it wait for that delegation. Tasks 1–8 do not. If the delegation is late, the fallback is a cheap domain registered in the account for staging only; that needs the owner's and the PM's OK and is not built here.
2. **Deploy inputs live in the private context repo**, one JSON file per environment (`docs/notes/infra/deploy-inputs/staging.json`): host, zone name and id, sender, alarm inbox, allowed staff domains, bootstrap emails, staging email allow-list, CORS origins. Without a file the CDK app composes only `EsNetwork`, `EsData` and `EsCi`.
3. 🔴 **CI deploys the image through the ECS API, not through `cdk deploy`** (spec §9.3 said CDK). Reason: with one AWS account, the CDK bootstrap roles can change any stack, production included, so a staging CI role built on them could not be limited to staging. With this split the staging role can only swap the image of the staging services. Infrastructure changes stay hand-run by the owner.
4. **One ECR repository, immutable tags.** Tag = commit SHA. Lifecycle: keep 20 `prod-*` images, and 30 of the rest. The production deploy adds `prod-<sha>` to the image it rolls out.
5. **GitHub → AWS through OIDC, one role per GitHub environment** (`es-ci-staging`, `es-ci-production`). The staging job runs in the GitHub environment `staging` (branch `main` only); the production job in `production` (required reviewer). The AWS account id is stored as the GitHub secret `AWS_ACCOUNT_ID` only so that GitHub masks it in the public logs; it is not a credential.
6. 🔴 **Pull requests get no AWS access** (spec §9.3 asked for `cdk diff` on PRs). A PR on a public repo must not hold credentials. The infra tests synthesize every stack, which replaces `cdk synth`; the owner runs `cdk diff` by hand before each infrastructure deploy.
7. **ARM everywhere:** `ubuntu-24.04-arm` runners build for ARM Fargate natively.
8. **Runtime image `aspnet:10.0-noble`**, not chiseled: it has tzdata and ICU (S0-3 carry-over: the jobs role resolves `Asia/Singapore` at start-up). The CI smoke test starts the image with both roles, so a missing zone fails the build.
9. **Database connection from parts.** On AWS the task gets `Database__Host`, `Database__Username`, `Database__Password` (the last two from the secret `es/<env>/db-app`) and the app builds the connection string: `SslMode=Require`, `Maximum Pool Size=50`. Locally `ConnectionStrings:Default` keeps working. Certificate pinning (`VerifyFull` with the RDS CA bundle) is left for the production go-live.
10. 🔴 **The app refuses to start when the database is missing a migration** (outside Development and Testing; switch `Database:RequireMigrated`, default true). Migrations stay hand-run (spec §5); this turns "forgot the script" from a broken staging into a failed deploy with the old version still serving.
11. **`Email:AllowedRecipients`** (exact addresses or `@domain`; empty = everyone). Staging must set it. A skipped email logs one Warning with the masked address.
12. **Compression for static text only** (`text/html`, `text/css`, JavaScript, SVG), Brotli or gzip. JSON stays uncompressed: API responses carry tokens, and compressing secrets next to caller-chosen text over HTTPS is the BREACH pattern.
13. **Services.** Staging: one service `es-staging-api`, 1 task, `App__Role=All`. Production: `es-production-api` (2 tasks, scaling to 4 at 60 % CPU or 1,000 requests per task per minute, `App__Role=Api`) and `es-production-jobs` (1 task, `App__Role=Jobs`).
14. **WAF on both environments:** the four AWS managed groups of spec §9.2, a rate rule of 2,000 requests per 5 minutes per IP, and a tighter one of 100 per 5 minutes per IP on `/api/v1/auth/*` and `/admin/api/auth/*`. This covers the S0-3 flood carry-over and is a first step on open decision 12 (staff sign-in hardening); it does not close it.
15. **Alarms** go to one SNS topic per environment with an email subscription (`alarmEmail`): load balancer 5xx (5 in 5 minutes), unhealthy targets, no running task, Error lines (5 in 5 minutes; the 5xx summary line is not counted twice), a job failed permanently (1), outside-call failures (5 in 5 minutes), staff codes locked (3 in an hour), database CPU above 80 % for 15 minutes, database connections, database free storage below 5 GB.
16. **Staging keeps `/swagger` and `/openapi/v1.json` public** (S0-2 decision 9). The document holds no secret; the same file is already in the public repo.
17. **The JWT signing key is generated by Secrets Manager** (`es/<env>/customer-signing-key`, 64 letters and digits, which the app reads as base64 of 48 bytes). Nobody types or sees it.
18. **Email domain per environment** (`staging.<zone>` and `<zone>`), with DKIM, a MAIL FROM subdomain (`mail.<domain>`) and DMARC `p=quarantine`. The client's main domain and its mail are never touched.
19. **Production is coded and tested, not deployed.** Its stacks, role and workflow exist (spec §11 item 2). Three checks stay for the go-live: RDS Proxy connection pinning (spec §9.2), the empty-key-ring race when `api` and `jobs` start together for the first time, and `VerifyFull`.
20. **No load balancer or WAF access logs yet.** They need an S3 bucket, which arrives in S2.

```csharp
        var configuration = new ConfigurationManager();
        configuration.AddInMemoryCollection(values.ToDictionary(v => v.Key, v => (string?)v.Value));
        return configuration;

    public void Parts_become_the_connection_string()
    {
        var configuration = Config(("Database:Host", "db.internal.test"), ("Database:Username", "es_app"), ("Database:Password", "p;w='d"));

        built.Host.Should().Be("db.internal.test");

        built.Database.Should().Be("extraspace");

        built.Password.Should().Be("p;w='d");

        configuration.GetConnectionString("Default").Should().Be("Host=localhost;Port=5433;Database=extraspace;Username=postgres");
```

```csharp
using Npgsql;

namespace ExtraSpace.Api.Platform.Data;

internal static class DatabaseConnection
{
    /// <summary>
    /// On AWS the task gets the host and the Secrets Manager user and password as separate values,
    /// so a password rotation never means editing a connection string. Locally ConnectionStrings:Default is set whole.
    /// </summary>
    public static void Compose(IConfigurationManager configuration)
    {
        var database = configuration.GetSection("Database");
        if (database["Host"] is not { Length: > 0 } host) return;
```

```csharp
using System.Text.Json;

namespace ExtraSpace.Infra;

/// <summary>
/// Per-environment values that must not sit in the public repo (host, zone id, addresses).
/// They live as &lt;env&gt;.json in the folder named by ES_DEPLOY_INPUTS (the private context repo).
/// </summary>
public sealed record DeployInputs
{
    public required string Host { get; init; }
    public required string ZoneName { get; init; }
    public required string ZoneId { get; init; }
    public required string EmailFrom { get; init; }
    public required string AlarmEmail { get; init; }
    public string[] AdminEmailDomains { get; init; } = [];
    public string[] BootstrapEmails { get; init; } = [];
    public string[] EmailAllowedRecipients { get; init; } = [];
    public string[] CorsOrigins { get; init; } = [];

    public string EmailFromAddress => EmailFrom.Contains('<')
        ? EmailFrom[(EmailFrom.IndexOf('<') + 1)..].Trim().TrimEnd('>').Trim()
        : EmailFrom.Trim();

    public string EmailDomain => EmailFromAddress[(EmailFromAddress.IndexOf('@') + 1)..];

    public static DeployInputs? Load(string? directory, string envName)
    {
        if (string.IsNullOrWhiteSpace(directory)) return null;
        var path = Path.Combine(directory, $"{envName}.json");
        if (!File.Exists(path)) return null;
        return JsonSerializer.Deserialize<DeployInputs>(File.ReadAllText(path), new JsonSerializerOptions { PropertyNameCaseInsensitive = true })
            ?? throw new InvalidOperationException($"{path} is empty.");
    }

    public DeployInputs Validated(EnvConfig config)
    {
        if (!InZone(Host)) Fail(config, "host", $"must be {ZoneName} or a name inside it");
        if (!EmailFromAddress.Contains('@') || !InZone(EmailDomain)) Fail(config, "emailFrom", $"must be an address inside {ZoneName}");
        if (!AlarmEmail.Contains('@')) Fail(config, "alarmEmail", "must be an email address");
        // Empty would let any address be added as staff and receive a sign-in code.
        if (AdminEmailDomains.Length == 0) Fail(config, "adminEmailDomains", "must list the company's email domains");
        // Once SES leaves the sandbox, staging could email anyone who types an address into it.
```

```csharp
public sealed class CiStack : Stack

    public static string TaskRoleName(string env) => $"es-{env}-task";
    public static string ExecutionRoleName(string env) => $"es-{env}-task-execution";
    public static string DeployRoleName(string env) => $"es-ci-{env}";

    public CiStack(Construct scope, string id, IStackProps props) : base(scope, id, props)
    {
        // The L1 resource: the L2 construct deploys a custom-resource Lambda.
        var provider = new CfnOIDCProvider(this, "GitHub", new CfnOIDCProviderProps
        {
            Url = $"https://{GitHubIssuer}",
            ClientIdList = new[] { "sts.amazonaws.com" },
        });

        var repository = new Repository(this, "Images", new RepositoryProps
        {
            RepositoryName = RepositoryName,
            ImageTagMutability = TagMutability.IMMUTABLE,
            ImageScanOnPush = true,
            RemovalPolicy = RemovalPolicy.RETAIN,
            LifecycleRules = new ILifecycleRule[]
            {
                // Rule 1 claims production images first, so the count rule below can never expire one that is running.
                new LifecycleRule { RulePriority = 1, Description = "keep 20 production images", TagPrefixList = new[] { "prod-" }, MaxImageCount = 20 },
                new LifecycleRule { RulePriority = 2, Description = "keep 30 other images", TagStatus = TagStatus.ANY, MaxImageCount = 30 },
            },
        });

        foreach (var config in EnvConfig.All) DeployRole(provider, repository, config);
    }

    private void DeployRole(CfnOIDCProvider provider, Repository repository, EnvConfig config)
    {
        var env = config.Name;
        var role = new Role(this, $"DeployRole{env}", new RoleProps
        {
            RoleName = DeployRoleName(env),
            Description = $"GitHub Actions deploys of {GitHubRepo}, GitHub environment {env}",
            MaxSessionDuration = Duration.Hours(1),
            AssumedBy = new WebIdentityPrincipal(provider.AttrArn, new Dictionary<string, object>
            {
                ["StringEquals"] = new Dictionary<string, object>
                {
                    [$"{GitHubIssuer}:aud"] = "sts.amazonaws.com",
                    [$"{GitHubIssuer}:sub"] = $"repo:{GitHubRepo}:environment:{env}",
                },
            }),
        });

        if (config.IsProduction)
        {
            // Production never builds: it promotes an image staging already ran, and adds the prod-<sha> tag to it.
            repository.GrantPull(role);
            Allow(role, new[] { "ecr:PutImage", "ecr:DescribeImages" }, repository.RepositoryArn);
            Allow(role, new[] { "ssm:GetParameter" }, Parameter(EnvConfig.Staging.Name));
        }
        else
        {
            repository.GrantPullPush(role);
            Allow(role, new[] { "ecr:DescribeImages" }, repository.RepositoryArn);
        }

        Allow(role, new[] { "ssm:GetParameter", "ssm:PutParameter" }, Parameter(env));
        Allow(role, new[] { "ecs:DescribeServices", "ecs:UpdateService" },
            FormatArn(new ArnComponents { Service = "ecs", Resource = "service", ResourceName = $"{ClusterName(env)}/*" }));
        // These three have no resource-level permissions. What limits a new task definition is iam:PassRole below.
        Allow(role, new[] { "ecs:ListServices", "ecs:DescribeTaskDefinition", "ecs:RegisterTaskDefinition" }, "*");
        role.AddToPolicy(new PolicyStatement(new PolicyStatementProps
        {
            Actions = new[] { "iam:PassRole" },
            Resources = new[]
            {
                FormatArn(new ArnComponents { Service = "iam", Region = "", Resource = "role", ResourceName = TaskRoleName(env) }),
                FormatArn(new ArnComponents { Service = "iam", Region = "", Resource = "role", ResourceName = ExecutionRoleName(env) }),
            },
            Conditions = new Dictionary<string, object>
            {
                ["StringEquals"] = new Dictionary<string, object> { ["iam:PassedToService"] = "ecs-tasks.amazonaws.com" },
            },
        }));
    }

    private string Parameter(string env) =>
        FormatArn(new ArnComponents { Service = "ssm", Resource = "parameter", ResourceName = ImageTagParameter(env).TrimStart('/') });

    private static void Allow(Role role, string[] actions, string resource) =>
        role.AddToPolicy(new PolicyStatement(new PolicyStatementProps { Actions = actions, Resources = new[] { resource } }));
```

```csharp
using Amazon.CDK.AWS.CertificateManager;
using Amazon.CDK.AWS.Route53;
using Amazon.CDK.AWS.SES;
using Constructs;

namespace ExtraSpace.Infra.Stacks;

public sealed class EdgeStackProps : StackProps
{
    public required EnvConfig Config { get; init; }
    public required DeployInputs Inputs { get; init; }
}

/// <summary>The HTTPS certificate and the email domain. Both are proven through DNS records in the delegated zone, so they sit apart from the app: slow to create, rarely changed.</summary>
public sealed class EdgeStack : Stack
{
    public ICertificate Certificate { get; }

    public EdgeStack(Construct scope, string id, EdgeStackProps props) : base(scope, id, props)
    {
        var inputs = props.Inputs;
        var domain = inputs.EmailDomain;
        // Attributes, not a lookup: a lookup calls AWS at synth time and writes the account id to cdk.context.json.
        var zone = HostedZone.FromHostedZoneAttributes(this, "Zone", new HostedZoneAttributes
        {
            HostedZoneId = inputs.ZoneId,
            ZoneName = inputs.ZoneName,
        });

        Certificate = new Certificate(this, "Certificate", new CertificateProps
        {
            DomainName = inputs.Host,
            Validation = CertificateValidation.FromDns(zone),
        });

        var identity = new EmailIdentity(this, "EmailIdentity", new EmailIdentityProps
        {
            Identity = Identity.Domain(domain),
            MailFromDomain = $"mail.{domain}",
        });

        // The DKIM names are tokens, so they go in as L1 records: the L2 record would append the zone name again.
        var index = 0;
        foreach (var record in identity.DkimRecords)
        {
            _ = new CfnRecordSet(this, $"Dkim{++index}", new CfnRecordSetProps
            {
                HostedZoneId = inputs.ZoneId,
                Name = record.Name,
                Type = "CNAME",
                Ttl = "1800",
                ResourceRecords = new[] { record.Value },
            });
        }

        _ = new MxRecord(this, "MailFromMx", new MxRecordProps
        {
            Zone = zone,
            RecordName = $"mail.{domain}.",
            Values = new IMxRecordValue[] { new MxRecordValue { Priority = 10, HostName = $"feedback-smtp.{Region}.amazonses.com" } },
        });
        _ = new TxtRecord(this, "MailFromSpf", new TxtRecordProps
        {
            Zone = zone,
            RecordName = $"mail.{domain}.",
            Values = new[] { "v=spf1 include:amazonses.com ~all" },
        });
        _ = new TxtRecord(this, "Dmarc", new TxtRecordProps
        {
            Zone = zone,
            RecordName = $"_dmarc.{domain}.",
            Values = new[] { "v=DMARC1; p=quarantine" },
        });

        _ = new CfnOutput(this, "CertificateArn", new CfnOutputProps { Value = Certificate.CertificateArn });
    }
}
```

```csharp
using Amazon.CDK;
using Amazon.CDK.AWS.CertificateManager;
using Amazon.CDK.AWS.EC2;
using Amazon.CDK.AWS.ECR;
using Amazon.CDK.AWS.ECS;
using Amazon.CDK.AWS.ElasticLoadBalancingV2;
using Amazon.CDK.AWS.IAM;
using Amazon.CDK.AWS.Logs;
using Amazon.CDK.AWS.Route53;
using Amazon.CDK.AWS.Route53.Targets;
using Amazon.CDK.AWS.SSM;
using Constructs;
using EcsSecret = Amazon.CDK.AWS.ECS.Secret;
using HealthCheck = Amazon.CDK.AWS.ElasticLoadBalancingV2.HealthCheck;
using Secret = Amazon.CDK.AWS.SecretsManager.Secret;
using SecretProps = Amazon.CDK.AWS.SecretsManager.SecretProps;
using SecretStringGenerator = Amazon.CDK.AWS.SecretsManager.SecretStringGenerator;

namespace ExtraSpace.Infra.Stacks;

public sealed class AppStackProps : StackProps
{
    public required EnvConfig Config { get; init; }
    public required DeployInputs Inputs { get; init; }
    public required IVpc Vpc { get; init; }
    public required DataStack Data { get; init; }
    public required ICertificate Certificate { get; init; }
}

public sealed class AppStack : Stack
{
    private const int ContainerPort = 8080;
    private const int PostgresPort = 5432;

    public ApplicationLoadBalancer LoadBalancer { get; }
    public ApplicationTargetGroup TargetGroup { get; }
    public IReadOnlyList<LogGroup> LogGroups { get; }
    public IReadOnlyList<FargateService> Services { get; }

    public AppStack(Construct scope, string id, AppStackProps props) : base(scope, id, props)
    {
        var config = props.Config;
        var inputs = props.Inputs;
        var env = config.Name;
        var removal = config.IsProduction ? RemovalPolicy.RETAIN : RemovalPolicy.DESTROY;

        // CI writes the tag after each roll-out; an SSM-typed stack parameter reads it at deploy time (no lookup at synth).
        var imageTag = StringParameter.ValueForStringParameter(this, CiStack.ImageTagParameter(env));
        var repository = Repository.FromRepositoryName(this, "Images", CiStack.RepositoryName);

        var albSecurityGroup = new SecurityGroup(this, "AlbSg", new SecurityGroupProps
        {
            Vpc = props.Vpc,
            Description = $"ExtraSpace {env} load balancer",
            AllowAllOutbound = false,
        });
        albSecurityGroup.AddIngressRule(Peer.AnyIpv4(), Port.Tcp(443), "HTTPS");
        albSecurityGroup.AddIngressRule(Peer.AnyIpv4(), Port.Tcp(80), "HTTP, redirected to HTTPS");

        // No inbound rule here: the only one is added below by the listener, from the load balancer.
        // The app trusts X-Forwarded-For from any caller, so nothing else may ever reach a task.
        var taskSecurityGroup = new SecurityGroup(this, "TaskSg", new SecurityGroupProps
        {
            Vpc = props.Vpc,
            Description = $"ExtraSpace {env} app tasks",
            AllowAllOutbound = true,
        });

        // In this stack, not the data stack: the data stack must not depend on the app.
        _ = new CfnSecurityGroupIngress(this, "DbFromTasks", new CfnSecurityGroupIngressProps
        {
            GroupId = props.Data.AppEntrySecurityGroup.SecurityGroupId,
            SourceSecurityGroupId = taskSecurityGroup.SecurityGroupId,
            IpProtocol = "tcp",
            FromPort = PostgresPort,
            ToPort = PostgresPort,
            Description = "app tasks to PostgreSQL",
        });

        var signingKey = new Secret(this, "CustomerSigningKey", new SecretProps
        {
            SecretName = $"es/{env}/customer-signing-key",
            Description = $"JWT signing key for customer access tokens ({env})",
            // 64 letters and digits are valid base64 for 48 bytes: what CustomerAuth:SigningKey expects.
            GenerateSecretString = new SecretStringGenerator { PasswordLength = 64, ExcludePunctuation = true },
            RemovalPolicy = removal,
        });

        var cluster = new Cluster(this, "Cluster", new ClusterProps
        {
            ClusterName = CiStack.ClusterName(env),
            Vpc = props.Vpc,
            ContainerInsightsV2 = ContainerInsights.ENABLED,
        });

        // Fixed names: the CI deploy role may pass exactly these two roles.
        var executionRole = new Role(this, "ExecutionRole", new RoleProps
        {
            RoleName = CiStack.ExecutionRoleName(env),
            AssumedBy = new ServicePrincipal("ecs-tasks.amazonaws.com"),
        });
        var taskRole = new Role(this, "TaskRole", new RoleProps
        {
            RoleName = CiStack.TaskRoleName(env),
            AssumedBy = new ServicePrincipal("ecs-tasks.amazonaws.com"),
        });
        var keyRing = $"es/{env}/data-protection";
        taskRole.AddToPolicy(new PolicyStatement(new PolicyStatementProps
        {
            Actions = new[] { "ssm:GetParametersByPath", "ssm:PutParameter" },
            Resources = new[]
            {
                FormatArn(new ArnComponents { Service = "ssm", Resource = "parameter", ResourceName = keyRing }),
                FormatArn(new ArnComponents { Service = "ssm", Resource = "parameter", ResourceName = $"{keyRing}/*" }),
            },
        }));
        // identity/*: while SES is in the sandbox it also checks the recipient's identity. The sender is pinned instead.
        taskRole.AddToPolicy(new PolicyStatement(new PolicyStatementProps
        {
            Actions = new[] { "ses:SendEmail" },
            Resources = new[] { FormatArn(new ArnComponents { Service = "ses", Resource = "identity", ResourceName = "*" }) },
            Conditions = new Dictionary<string, object>
            {
                ["StringEquals"] = new Dictionary<string, object> { ["ses:FromAddress"] = inputs.EmailFromAddress },
            },
        }));

        var settings = new Dictionary<string, string>
        {
            ["ASPNETCORE_ENVIRONMENT"] = config.AspNetEnvironment,
            ["App__Version"] = imageTag,
            ["App__MinVersion__ios"] = "0.0.0",
            ["App__MinVersion__android"] = "0.0.0",
            ["App__MinVersion__web"] = "0.0.0",
            ["Database__Host"] = props.Data.AppHost,
            ["Database__Name"] = DataStack.DatabaseName,
            ["DataProtection__SsmPath"] = $"/{keyRing}/",
            ["Email__From"] = inputs.EmailFrom,
        };
        AddList(settings, "Admin__AllowedEmailDomains", inputs.AdminEmailDomains);
        AddList(settings, "Admin__BootstrapEmails", inputs.BootstrapEmails);
        AddList(settings, "Cors__AllowedOrigins", inputs.CorsOrigins);
        if (!config.IsProduction) AddList(settings, "Email__AllowedRecipients", inputs.EmailAllowedRecipients);

        var secrets = new Dictionary<string, EcsSecret>
        {
            ["Database__Username"] = EcsSecret.FromSecretsManager(props.Data.AppUserSecret, "username"),
            ["Database__Password"] = EcsSecret.FromSecretsManager(props.Data.AppUserSecret, "password"),
            ["CustomerAuth__SigningKey"] = EcsSecret.FromSecretsManager(signingKey),
        };

        var logGroups = new List<LogGroup>();
        var services = new List<FargateService>();

        FargateService Service(string name, string role, int cpu, int memory, int count, bool web)
        {
            var logGroup = new LogGroup(this, $"{name}Logs", new LogGroupProps
            {
                LogGroupName = $"/extraspace/{env}/{name}",
                Retention = config.LogRetentionDays == 90 ? RetentionDays.THREE_MONTHS : RetentionDays.TWO_WEEKS,
                RemovalPolicy = removal,
            });
            logGroups.Add(logGroup);

            var definition = new FargateTaskDefinition(this, $"{name}Task", new FargateTaskDefinitionProps
            {
                Family = $"es-{env}-{name}",
                Cpu = cpu,
                MemoryLimitMiB = memory,
                RuntimePlatform = new RuntimePlatform
                {
                    CpuArchitecture = CpuArchitecture.ARM64,
                    OperatingSystemFamily = OperatingSystemFamily.LINUX,
                },
                TaskRole = taskRole,
                ExecutionRole = executionRole,
            });
            definition.AddContainer("app", new ContainerDefinitionOptions
            {
                Image = ContainerImage.FromEcrRepository(repository, imageTag),
                Environment = new Dictionary<string, string>(settings) { ["App__Role"] = role },
                Secrets = secrets,
                Logging = LogDriver.AwsLogs(new AwsLogDriverProps { LogGroup = logGroup, StreamPrefix = name }),
                PortMappings = web ? new IPortMapping[] { new PortMapping { ContainerPort = ContainerPort } } : null,
            });

            var service = new FargateService(this, $"{name}Service", new FargateServiceProps
            {
                ServiceName = $"es-{env}-{name}",
                Cluster = cluster,
                TaskDefinition = definition,
                DesiredCount = count,
                VpcSubnets = new SubnetSelection { SubnetGroupName = "app" },
                SecurityGroups = new ISecurityGroup[] { taskSecurityGroup },
                AssignPublicIp = false,
                CircuitBreaker = new DeploymentCircuitBreaker { Enable = true, Rollback = true },
                MinHealthyPercent = 100,
                MaxHealthyPercent = 200,
                HealthCheckGracePeriod = web ? Duration.Seconds(60) : null,
                PropagateTags = PropagatedTagSource.SERVICE,
            });
            services.Add(service);
            return service;
        }

        var api = Service("api", config.SeparateJobs ? "Api" : "All", config.ApiCpu, config.ApiMemoryMiB, config.ApiCount, web: true);
        if (config.SeparateJobs)
            Service("jobs", "Jobs", config.JobsCpu, config.JobsMemoryMiB, 1, web: false);

        LoadBalancer = new ApplicationLoadBalancer(this, "Alb", new ApplicationLoadBalancerProps
        {
            LoadBalancerName = $"es-{env}",
            Vpc = props.Vpc,
            InternetFacing = true,
            VpcSubnets = new SubnetSelection { SubnetType = SubnetType.PUBLIC },
            SecurityGroup = albSecurityGroup,
            DropInvalidHeaderFields = true,
            IdleTimeout = Duration.Seconds(60),
        });
        // The per-IP limits read the last X-Forwarded-For hop. Stated, so a change of the AWS default cannot move it.
        LoadBalancer.SetAttribute("routing.http.xff_header_processing.mode", "append");

        var https = LoadBalancer.AddListener("Https", new BaseApplicationListenerProps
        {
            Port = 443,
            Protocol = ApplicationProtocol.HTTPS,
            Certificates = new IListenerCertificate[] { ListenerCertificate.FromCertificateManager(props.Certificate) },
            SslPolicy = SslPolicy.RECOMMENDED_TLS,
            Open = false,
        });
        TargetGroup = https.AddTargets("Api", new AddApplicationTargetsProps
        {
            Port = ContainerPort,
            Protocol = ApplicationProtocol.HTTP,
            Targets = new IApplicationLoadBalancerTarget[] { api },
            DeregistrationDelay = Duration.Seconds(30),
            HealthCheck = new HealthCheck
            {
                Path = "/health/live",
                HealthyHttpCodes = "200",
                Interval = Duration.Seconds(15),
                Timeout = Duration.Seconds(5),
                HealthyThresholdCount = 2,
                UnhealthyThresholdCount = 3,
            },
        });
        LoadBalancer.AddRedirect(new ApplicationLoadBalancerRedirectConfig { SourcePort = 80, TargetPort = 443, Open = false });

        if (config.ApiMaxCount > config.ApiCount)
        {
            var scaling = api.AutoScaleTaskCount(new Amazon.CDK.AWS.ApplicationAutoScaling.EnableScalingProps
            {
                MinCapacity = config.ApiCount,
                MaxCapacity = config.ApiMaxCount,
            });
            scaling.ScaleOnCpuUtilization("Cpu", new CpuUtilizationScalingProps { TargetUtilizationPercent = 60 });
            scaling.ScaleOnRequestCount("Requests", new RequestCountScalingProps { RequestsPerTarget = 1000, TargetGroup = TargetGroup });
        }

        var zone = HostedZone.FromHostedZoneAttributes(this, "Zone", new HostedZoneAttributes
        {
            HostedZoneId = inputs.ZoneId,
            ZoneName = inputs.ZoneName,
        });
        _ = new ARecord(this, "HostRecord", new ARecordProps
        {
            Zone = zone,
            RecordName = inputs.Host + ".",
            Target = RecordTarget.FromAlias(new LoadBalancerTarget(LoadBalancer)),
        });

        LogGroups = logGroups;
        Services = services;

        _ = new CfnOutput(this, "Url", new CfnOutputProps { Value = $"https://{inputs.Host}" });
        _ = new CfnOutput(this, "ClusterName", new CfnOutputProps { Value = cluster.ClusterName });
    }

    private static void AddList(Dictionary<string, string> settings, string key, string[] values)
    {
        for (var i = 0; i < values.Length; i++) settings[$"{key}__{i}"] = values[i];
    }
}
```

```csharp
using Amazon.CDK.AWS.WAFv2;
using Constructs;

namespace ExtraSpace.Infra.Stacks;

/// <summary>AWS WAF on the load balancer: the managed groups of S0 spec §9.2 plus two rate rules.</summary>
internal sealed class WebFirewall : Construct
{
    private static readonly string[] ManagedGroups =
    [
        "AWSManagedRulesCommonRuleSet",
        "AWSManagedRulesKnownBadInputsRuleSet",
        "AWSManagedRulesAmazonIpReputationList",
        "AWSManagedRulesSQLiRuleSet",
    ];

    // Sign-in paths, lower case: the rule lower-cases the request path before it compares.
    private static readonly string[] AuthPaths = ["/api/v1/auth/", "/admin/api/auth/"];

    public WebFirewall(Construct scope, string id, string env, string loadBalancerArn) : base(scope, id)
    {
        var rules = new List<object>();
        var priority = 0;
        foreach (var group in ManagedGroups)
        {
            priority += 10;
            rules.Add(new CfnWebACL.RuleProperty
            {
                Name = group,
                Priority = priority,
                // None = keep the group's own block actions.
                OverrideAction = new CfnWebACL.OverrideActionProperty { None = new Dictionary<string, object>() },
                Statement = new CfnWebACL.StatementProperty
                {
                    ManagedRuleGroupStatement = new CfnWebACL.ManagedRuleGroupStatementProperty { VendorName = "AWS", Name = group },
                },
                VisibilityConfig = Visibility($"es-{env}-{group}"),
            });
        }

        rules.Add(RateRule("RateAuth", priority += 10, 100, env, new CfnWebACL.StatementProperty
        {
            OrStatement = new CfnWebACL.OrStatementProperty
            {
                Statements = AuthPaths.Select(path => (object)new CfnWebACL.StatementProperty
                {
                    ByteMatchStatement = new CfnWebACL.ByteMatchStatementProperty
                    {
                        SearchString = path,
                        FieldToMatch = new CfnWebACL.FieldToMatchProperty { UriPath = new Dictionary<string, object>() },
                        PositionalConstraint = "STARTS_WITH",
                        // ASP.NET routes ignore case, a byte match does not.
                        TextTransformations = new object[] { new CfnWebACL.TextTransformationProperty { Priority = 0, Type = "LOWERCASE" } },
                    },
                }).ToArray(),
            },
        }));
        rules.Add(RateRule("RateAll", priority + 10, 2000, env, scopeDown: null));

        var acl = new CfnWebACL(this, "Acl", new CfnWebACLProps
        {
            Name = $"es-{env}",
            Scope = "REGIONAL",
            DefaultAction = new CfnWebACL.DefaultActionProperty { Allow = new CfnWebACL.AllowActionProperty() },
            VisibilityConfig = Visibility($"es-{env}"),
            Rules = rules.ToArray(),
        });

        _ = new CfnWebACLAssociation(this, "Association", new CfnWebACLAssociationProps
        {
            ResourceArn = loadBalancerArn,
            WebAclArn = acl.AttrArn,
        });
    }

    private static CfnWebACL.RuleProperty RateRule(string name, int priority, int limit, string env, CfnWebACL.StatementProperty? scopeDown) => new()
    {
        Name = name,
        Priority = priority,
        Action = new CfnWebACL.RuleActionProperty { Block = new CfnWebACL.BlockActionProperty() },
        Statement = new CfnWebACL.StatementProperty
        {
            RateBasedStatement = new CfnWebACL.RateBasedStatementProperty
            {
                Limit = limit,
                EvaluationWindowSec = 300,
                // The load balancer is the edge, so the source address is the real client.
                AggregateKeyType = "IP",
                ScopeDownStatement = scopeDown,
            },
        },
        VisibilityConfig = Visibility($"es-{env}-{name}"),
    };

    private static CfnWebACL.VisibilityConfigProperty Visibility(string metric) => new()
    {
        CloudWatchMetricsEnabled = true,
        SampledRequestsEnabled = true,
        MetricName = metric,
    };
}
```

```csharp
namespace ExtraSpace.Infra.Stacks;

internal sealed class ObservabilityProps

/// <summary>The saved log queries, metric filters and alarms of S0 spec §4.4 and §9.2.</summary>
internal sealed class Observability : Construct

    private const string SummaryTemplate = "HTTP {method} {route} responded {status} in {elapsedMs} ms";
    private readonly string _env;
    private readonly string _namespace;
    private readonly Topic _topic;

    public Observability(Construct scope, string id, ObservabilityProps props) : base(scope, id)
    {
        _env = props.Config.Name;
        _namespace = $"ExtraSpace/{_env}";
        _topic = new Topic(this, "Alarms", new TopicProps { TopicName = $"es-{_env}-alarms" });
        _topic.AddSubscription(new EmailSubscription(props.AlarmEmail));

        var groupNames = props.LogGroups.Select(g => g.LogGroupName).ToArray();

            "fields @timestamp, role, level, message, exception\n" +
            "| filter traceId = \"PASTE-ID\" or correlationId = \"PASTE-ID\"\n" +
            "| sort @timestamp asc\n| limit 1000");
        Query("Errors", groupNames,
            "filter level = \"Error\" and ispresent(exception)\n" +
            "| parse exception /^(?<exceptionType>[\\w\\.]+)/\n" +
            "| stats count(*) as errors by coalesce(route, jobName, \"-\") as source, exceptionType\n" +
            "| sort errors desc");
        // Static files answer before routing and log route "(unmatched)"; they would drown the list.
        Query("Slow", groupNames,
            "fields @timestamp, route, status, elapsedMs, message, traceId\n" +
            $"| filter (messageTemplate = \"{SummaryTemplate}\" and elapsedMs > 1000 and route != \"(unmatched)\")\n" +
            "    or messageTemplate like /^Slow database command/\n" +
            "| sort elapsedMs desc\n| limit 200");
        Query("Outside-call failures", groupNames,
            "filter ispresent(integration) and outcome != \"ok\"\n" +
            "| stats count(*) as failures by integration, operation, outcome\n" +
            "| sort failures desc");
        Query("One user", groupNames,
            "fields @timestamp, level, method, route, status, message, traceId\n" +
            "| filter customerId = \"PASTE-ID\" or staffId = \"PASTE-ID\"\n" +
            "| sort @timestamp desc\n| limit 500");

        var errorLines = LogMetric(props.LogGroups, "ErrorLines",
            $"{{ (($.level = \"Error\") || ($.level = \"Fatal\")) && ($.messageTemplate != \"{SummaryTemplate}\") }}");
        var jobsFailed = LogMetric(props.LogGroups, "JobsFailedPermanently",
            "{ $.messageTemplate = \"Job {jobName} failed permanently\" }");
        var outsideFailures = LogMetric(props.LogGroups, "OutsideCallFailures",
            "{ ($.integration = \"*\") && ($.outcome != \"ok\") }");
        var staffLocked = LogMetric(props.LogGroups, "StaffCodesLocked",
            "{ ($.messageTemplate = \"Login code {codeId} locked after too many wrong attempts\") && ($.purpose = \"Staff\") }");

        var albDimensions = new Dictionary<string, object> { ["LoadBalancer"] = props.LoadBalancer.LoadBalancerFullName };
        Alarm("5xx", Metric("AWS/ApplicationELB", "HTTPCode_Target_5XX_Count", albDimensions, "Sum", 5), 5, 1,
            ComparisonOperator.GREATER_THAN_OR_EQUAL_TO_THRESHOLD, "5 or more 5xx answers from the app in 5 minutes");
        Alarm("unhealthy-targets", Metric("AWS/ApplicationELB", "UnHealthyHostCount", new Dictionary<string, object>
            {
                ["LoadBalancer"] = props.LoadBalancer.LoadBalancerFullName,
                ["TargetGroup"] = props.TargetGroup.TargetGroupFullName,
            }, "Maximum", 1), 1, 3,
            ComparisonOperator.GREATER_THAN_OR_EQUAL_TO_THRESHOLD, "a task failed its health check for 3 minutes");

        foreach (var service in props.Services)

            // Startup crashes happen before Serilog starts, so no log line shows them: the task count does.

                {
                    ["ClusterName"] = CiStack.ClusterName(_env),
                    ["ServiceName"] = service.ServiceName,
                }, "Minimum", 1), 1, 5,
                ComparisonOperator.LESS_THAN_THRESHOLD, $"no {name} task has been running for 5 minutes", TreatMissingData.BREACHING);
        }

        Alarm("error-lines", errorLines(5), 5, 1, ComparisonOperator.GREATER_THAN_OR_EQUAL_TO_THRESHOLD, "5 or more Error lines in 5 minutes");
        Alarm("job-failed-permanently", jobsFailed(5), 1, 1, ComparisonOperator.GREATER_THAN_OR_EQUAL_TO_THRESHOLD, "a job used up its retries");

        Alarm("staff-codes-locked", staffLocked(60), 3, 1, ComparisonOperator.GREATER_THAN_OR_EQUAL_TO_THRESHOLD, "3 or more staff sign-in codes locked in an hour");

        var database = new Dictionary<string, object> { ["DBInstanceIdentifier"] = $"es-{_env}-postgres" };
        Alarm("db-cpu", Metric("AWS/RDS", "CPUUtilization", database, "Average", 5), 80, 3,

            ComparisonOperator.GREATER_THAN_OR_EQUAL_TO_THRESHOLD, "database connections near the limit");
        Alarm("db-free-storage", Metric("AWS/RDS", "FreeStorageSpace", database, "Minimum", 5), 5.0 * 1024 * 1024 * 1024, 1,
            ComparisonOperator.LESS_THAN_THRESHOLD, "less than 5 GB free on the database");

    private void Query(string name, string[] logGroupNames, string query) =>
        _ = new CfnQueryDefinition(this, $"Query{name.Replace(" ", "").Replace("-", "")}", new CfnQueryDefinitionProps
        {
            Name = $"extraspace/{_env}/{name}",
            LogGroupNames = logGroupNames,
            QueryString = query,
        });

    // One filter per log group, all feeding the same metric. Returns the metric for a period in minutes.
    private Func<int, Metric> LogMetric(IReadOnlyList<LogGroup> logGroups, string metricName, string pattern)
    {
        for (var i = 0; i < logGroups.Count; i++)
        {
            _ = new MetricFilter(this, $"{metricName}{i}", new MetricFilterProps
            {
                LogGroup = logGroups[i],
                MetricNamespace = _namespace,
                MetricName = metricName,
                FilterPattern = FilterPattern.Literal(pattern),
                MetricValue = "1",
            });
        }
        return minutes => Metric(_namespace, metricName, new Dictionary<string, object>(), "Sum", minutes);
    }

    private static Metric Metric(string ns, string name, Dictionary<string, object> dimensions, string statistic, int minutes) =>
        new(new MetricProps
        {
            Namespace = ns,
            MetricName = name,
            DimensionsMap = dimensions.ToDictionary(d => d.Key, d => (string)d.Value),
            Statistic = statistic,
            Period = Duration.Minutes(minutes),
        });

    private void Alarm(string name, Metric metric, double threshold, int periods, ComparisonOperator comparison, string description,
        TreatMissingData missing = TreatMissingData.NOT_BREACHING)
    {
        var alarm = new Alarm(this, $"Alarm{name.Replace("-", "")}", new AlarmProps
        {
            AlarmName = $"es-{_env}-{name}",
            AlarmDescription = description,
            Metric = metric,
            Threshold = threshold,
            EvaluationPeriods = periods,
            ComparisonOperator = comparison,
            TreatMissingData = missing,
        });
        alarm.AddAlarmAction(new SnsAction(_topic));
    }
}
```

`.github/scripts/deploy.sh` (executable):

```bash
#!/usr/bin/env bash
# Usage: deploy.sh <env> <image-tag>
# Rolls every service of cluster es-<env> to the image, waits, and only then records the tag in SSM.
# The app stack reads that parameter, so a later `cdk deploy` uses the image that is really running.
# CI logs are public: this script prints no task definition and no AWS response.
set -euo pipefail

env_name="$1"
tag="$2"
cluster="es-${env_name}"
parameter="/es/${env_name}/app/image-tag"
account="$(aws sts get-caller-identity --query Account --output text)"
image="${account}.dkr.ecr.${AWS_REGION}.amazonaws.com/extraspace/api:${tag}"
work="$(mktemp -d)"
trap 'rm -rf "$work"' EXIT

record_tag() {
  aws ssm put-parameter --name "$parameter" --type String --overwrite --value "$tag" >/dev/null
}

services="$(aws ecs list-services --cluster "$cluster" --query 'serviceArns' --output text 2>/dev/null || true)"
if [ -z "$services" ] || [ "$services" = "None" ]; then
  record_tag
  echo "::notice::No services in ${cluster} yet. The tag is recorded; create the app stack by hand (setup guide B7)."
  exit 0
fi

declare -a expected=()
for service in $services; do
  current="$(aws ecs describe-services --cluster "$cluster" --services "$service" --query 'services[0].taskDefinition' --output text)"
  aws ecs describe-task-definition --task-definition "$current" --query 'taskDefinition' --output json \
    | jq --arg image "$image" --arg tag "$tag" '
        del(.taskDefinitionArn, .revision, .status, .requiresAttributes, .compatibilities, .registeredAt, .registeredBy, .deregisteredAt)
        | .containerDefinitions[0].image = $image
        | .containerDefinitions[0].environment |= map(if .name == "App__Version" then .value = $tag else . end)' \
    > "$work/task-definition.json"
  registered="$(aws ecs register-task-definition --cli-input-json "file://$work/task-definition.json" \
    --query 'taskDefinition.taskDefinitionArn' --output text)"
  aws ecs update-service --cluster "$cluster" --service "$service" --task-definition "$registered" >/dev/null
  expected+=("$service $registered")
  echo "Rolling ${service##*/}."
done

# shellcheck disable=SC2086
aws ecs wait services-stable --cluster "$cluster" --services $services

# The circuit breaker rolls a failed deploy back, and the wait above then succeeds on the OLD version.
for pair in "${expected[@]}"; do
  service="${pair%% *}"
  registered="${pair##* }"
  running="$(aws ecs describe-services --cluster "$cluster" --services "$service" --query 'services[0].taskDefinition' --output text)"
  if [ "$running" != "$registered" ]; then
    echo "::error::${service##*/} was rolled back: the new tasks did not start. Check the ECS service events and the task's stop reason."
    exit 1
  fi
done

record_tag
echo "Deployed ${tag} to ${cluster}."
```
