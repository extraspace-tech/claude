# S0-1 Repo skeleton + AWS network and database — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. In this workspace the implementer is the Opus `implementer` agent; Tasks 4–6 are run by the main session only.

**Goal:** Create the `../CMS` solution skeleton and an AWS CDK app whose `EsNetwork-<env>` and `EsData-<env>` stacks build the VPC, NAT, PostgreSQL 18 database, bastion and database secrets; deploy them to **staging** and create the database users.

**Architecture:** One CDK app in C# (`infra/ExtraSpace.Infra`) composes two stacks per environment from one `EnvConfig` record (staging and production values side by side). `InfraComposer.Compose(app, account)` is the single place that builds and tags all stacks, so the tests (`tests/ExtraSpace.Infra.Tests`, CDK assertions) check exactly what `cdk deploy` deploys. Production stacks are synthesized and tested now but deployed later (before go-live), to avoid ~US$400/month of idle cost.

**Tech Stack:** .NET 10 (SDK 10.0.400), AWS CDK `Amazon.CDK.Lib` 2.273.0 + `Constructs` 10.8.1, xUnit v3 4.0.2, Node 24 (required by CDK's jsii runtime, already installed), AWS CLI 2.36 with profile `extraspace`.

**Spec:** `docs/superpowers/specs/2026-10-09-s0-foundation-design.md` (§3 layout, §5 data, §9.2 AWS), plus `docs/notes/infra/aws-setup-guide.md` (B3, B5) and `docs/superpowers/plans/2026-10-12-s0-plan-index.md`.

- Work on branch `s0-1-network-database`. **Never `git commit` or `git push`** — each task ends with a hand-off; the owner commits.
- No new `.md` file inside `../CMS` (a hook blocks it). Line endings LF.
- SDK pinned by `global.json`: `10.0.400`, `rollForward: latestFeature`. Target `net10.0`. Package versions only in `Directory.Packages.props`.
- Region `ap-southeast-1`; availability zones fixed to `ap-southeast-1a`, `ap-southeast-1b` (no context lookups, so no `cdk.context.json` with the account id).
- Stack names: `EsNetwork-staging`, `EsData-staging`, `EsNetwork-production`, `EsData-production`.
- Secret names: `es/<env>/db-master`, `es/<env>/db-app`, `es/<env>/db-readonly`.
- Tags on everything: `Project=extraspace-platform`, `ManagedBy=cdk`, `Environment=<env>`.
- PostgreSQL `18.6` (major `18`), database `extraspace`, master user `postgres`.
- Sizing (cost v4): staging VPC `10.10.0.0/16`, 1 NAT, `db.t4g.medium` single-AZ, 20→50 GB gp3, 7-day backups, no proxy; production VPC `10.20.0.0/16`, 2 NAT, `db.m8g.large` Multi-AZ, 50→200 GB gp3, 35-day backups, RDS Proxy, Database Insights advanced (Performance Insights 465 days).

- Test assertions library for later plans: **AwesomeAssertions** (Apache-2.0 fork), not FluentAssertions 8+ (commercial licence since v8). This deviates from spec §10's "FluentAssertions"; owner informed in the hand-off. S0-1's tests use only CDK's own `Template` assertions.

## Review Focus

1. **A deploy that deletes or replaces the production database** (stack delete, a property change that forces replacement) — expected: `Retain` policies + deletion protection + termination protection on production; pinned by Task 3 test `Production_database_is_retained_and_protected` and Task 2 test `Production_stacks_have_termination_protection`; Task 4 checks `cdk diff` shows no `[-]`/replace on the DB.
2. **The database reachable from anything but the bastion (and the proxy in production)** — expected: isolated subnets, not public, ingress only from those security groups; pinned by Task 3 tests `Database_is_private_and_only_bastion_and_proxy_may_connect` (both envs).
3. **Staging and production colliding** (same CIDR, secret name, identifier) — expected: every name carries the environment; pinned by Task 2 test `Vpc_has_the_environment_cidr_and_nat_count` and Task 3 test `Secrets_are_named_per_environment`.
4. **A password or account id ending up in the template or repo** — expected: passwords only generated by Secrets Manager, account only from the environment; pinned by Task 3 test `Master_password_is_never_in_the_template` and Task 2 test `Compose_works_without_an_account`.
5. **Elastic IP quota (5) exhausted by our NAT gateways** — expected: staging 1 + production 2 = 3; pinned by Task 2 test `Vpc_has_the_environment_cidr_and_nat_count` (EIP count per env).

using Amazon.CDK;
using Amazon.CDK.Assertions;

namespace ExtraSpace.Infra.Tests;

internal static class TestStacks
{
    private const string FakeAccount = "123456789012";
    private static readonly object Gate = new();
    private static IReadOnlyDictionary<string, Stack>? _stacks;
    private static readonly Dictionary<string, Template> Templates = new();

    public static Stack Stack(string stackName)
    {
        lock (Gate)
        {
            _stacks ??= InfraComposer.Compose(new App(), FakeAccount);
            return _stacks[stackName];
        }
    }

    public static Template For(string stackName)
    {
        lock (Gate)
        {
            if (!Templates.TryGetValue(stackName, out var template))
            {
                template = Template.FromStack(Stack(stackName));
                Templates[stackName] = template;
            }
            return template;
        }
    }
}

`infra/ExtraSpace.Infra/InfraComposer.cs`:

```csharp
using Amazon.CDK;
using ExtraSpace.Infra.Stacks;

namespace ExtraSpace.Infra;

public static class InfraComposer
{
    public const string Region = "ap-southeast-1";

    // Fixed zones: no context lookup, so no cdk.context.json holding the account id.
    public static readonly string[] AvailabilityZones = ["ap-southeast-1a", "ap-southeast-1b"];

    public static IReadOnlyDictionary<string, Stack> Compose(App app, string? account)
    {
        Tags.Of(app).Add("Project", "extraspace-platform");
        Tags.Of(app).Add("ManagedBy", "cdk");

        var stacks = new Dictionary<string, Stack>();
        foreach (var config in EnvConfig.All)
        {
            var env = new Amazon.CDK.Environment { Account = account, Region = Region };

            var network = new NetworkStack(app, $"EsNetwork-{config.Name}", new NetworkStackProps
            {
                Env = env,
                Config = config,
                TerminationProtection = config.IsProduction,
                Description = $"ExtraSpace platform network ({config.Name})",
            });

            var data = new DataStack(app, $"EsData-{config.Name}", new DataStackProps
            {
                Env = env,
                Config = config,
                Vpc = network.Vpc,
                TerminationProtection = config.IsProduction,
                Description = $"ExtraSpace platform database and bastion ({config.Name})",
            });

            foreach (var stack in new Stack[] { network, data })
            {
                Tags.Of(stack).Add("Environment", config.Name);
                stacks[stack.StackName] = stack;
            }
        }

        return stacks;
    }
}
```

using Amazon.CDK;
using Amazon.CDK.AWS.EC2;
using Constructs;

namespace ExtraSpace.Infra.Stacks;

public sealed class NetworkStackProps : StackProps
{
    public required EnvConfig Config { get; init; }
}

public sealed class NetworkStack : Stack
{
    public IVpc Vpc { get; }

    public NetworkStack(Construct scope, string id, NetworkStackProps props) : base(scope, id, props)
    {
        Vpc = new Amazon.CDK.AWS.EC2.Vpc(this, "Vpc", new VpcProps
        {
            VpcName = $"es-{props.Config.Name}",
            IpAddresses = IpAddresses.Cidr(props.Config.VpcCidr),
            AvailabilityZones = InfraComposer.AvailabilityZones,
            NatGateways = props.Config.NatGateways,
            // Nothing uses the default security group; leaving it alone avoids a custom-resource Lambda.
            RestrictDefaultSecurityGroup = false,
            SubnetConfiguration = new ISubnetConfiguration[]
            {
                new SubnetConfiguration { Name = "public", SubnetType = SubnetType.PUBLIC, CidrMask = 24 },
                new SubnetConfiguration { Name = "app", SubnetType = SubnetType.PRIVATE_WITH_EGRESS, CidrMask = 22 },
                new SubnetConfiguration { Name = "data", SubnetType = SubnetType.PRIVATE_ISOLATED, CidrMask = 24 },
            },
            GatewayEndpoints = new Dictionary<string, IGatewayVpcEndpointOptions>
            {
                ["S3"] = new GatewayVpcEndpointOptions { Service = GatewayVpcEndpointAwsService.S3 },
            },
        });
    }
}

using Amazon.CDK;
using Amazon.CDK.AWS.EC2;
using Amazon.CDK.AWS.Logs;
using Amazon.CDK.AWS.RDS;
using Amazon.CDK.AWS.SecretsManager;
using Constructs;

namespace ExtraSpace.Infra.Stacks;

public sealed class DataStackProps : StackProps
{
    public required EnvConfig Config { get; init; }
    public required IVpc Vpc { get; init; }
}

public sealed class DataStack : Stack
{
    public const string DatabaseName = "extraspace";
    public const string MasterUser = "postgres";
    private const string PostgresFullVersion = "18.6";
    private const string PostgresMajorVersion = "18";

    public DatabaseInstance Database { get; }
    public ISecurityGroup DatabaseSecurityGroup { get; }
    public ISecret AppUserSecret { get; }
    public ISecret ReadOnlyUserSecret { get; }
    public DatabaseProxy? Proxy { get; }
    public BastionHostLinux Bastion { get; }

    public DataStack(Construct scope, string id, DataStackProps props) : base(scope, id, props)
    {
        var config = props.Config;
        var vpc = props.Vpc;
        var identifier = $"es-{config.Name}-postgres";
        var removal = config.IsProduction ? RemovalPolicy.RETAIN : RemovalPolicy.DESTROY;

        DatabaseSecurityGroup = new SecurityGroup(this, "DbSg", new SecurityGroupProps
        {
            Vpc = vpc,
            Description = $"ExtraSpace {config.Name} PostgreSQL",
            AllowAllOutbound = false,
        });

        var bastionSecurityGroup = new SecurityGroup(this, "BastionSg", new SecurityGroupProps
        {
            Vpc = vpc,
            Description = $"ExtraSpace {config.Name} bastion, SSM only, no inbound",
            AllowAllOutbound = true,
        });

        // Reached only through SSM Session Manager port forwarding (aws-setup-guide B5); no SSH key, no inbound port.
        Bastion = new BastionHostLinux(this, "Bastion", new BastionHostLinuxProps
        {
            Vpc = vpc,
            InstanceName = $"es-{config.Name}-bastion",
            InstanceType = new InstanceType("t4g.nano"),
            MachineImage = MachineImage.LatestAmazonLinux2023(new AmazonLinux2023ImageSsmParameterProps
            {
                CpuType = AmazonLinuxCpuType.ARM_64,
            }),
            SecurityGroup = bastionSecurityGroup,
            SubnetSelection = new SubnetSelection { SubnetType = SubnetType.PRIVATE_WITH_EGRESS },
            RequireImdsv2 = true,
            BlockDevices = new IBlockDevice[]
            {
                new BlockDevice
                {
                    DeviceName = "/dev/xvda",
                    Volume = BlockDeviceVolume.Ebs(8, new EbsDeviceOptions
                    {
                        Encrypted = true,
                        VolumeType = EbsDeviceVolumeType.GP3,
                    }),
                },
            },
        });

        var engine = DatabaseInstanceEngine.Postgres(new PostgresInstanceEngineProps
        {
            Version = PostgresEngineVersion.Of(PostgresFullVersion, PostgresMajorVersion),
        });

        var parameters = new ParameterGroup(this, "DbParams", new ParameterGroupProps
        {
            Engine = engine,
            Description = $"ExtraSpace {config.Name} PostgreSQL parameters",
            Parameters = new Dictionary<string, string>
            {
                ["rds.force_ssl"] = "1",
                ["log_min_duration_statement"] = "500",
                ["idle_in_transaction_session_timeout"] = "60000",
            },
        });

        // Created here, with retention, so RDS does not create an unmanaged group and CDK needs no log-retention Lambda.
        var logGroup = new LogGroup(this, "DbLogs", new LogGroupProps
        {
            LogGroupName = $"/aws/rds/instance/{identifier}/postgresql",
            Retention = config.IsProduction ? RetentionDays.THREE_MONTHS : RetentionDays.TWO_WEEKS,
            RemovalPolicy = RemovalPolicy.DESTROY,
        });

        Database = new DatabaseInstance(this, "Postgres", new DatabaseInstanceProps
        {
            InstanceIdentifier = identifier,
            Engine = engine,
            InstanceType = new InstanceType(config.DbInstanceType),
            Vpc = vpc,
            VpcSubnets = new SubnetSelection { SubnetType = SubnetType.PRIVATE_ISOLATED },
            SecurityGroups = new[] { DatabaseSecurityGroup },
            Credentials = Credentials.FromGeneratedSecret(MasterUser, new CredentialsBaseOptions
            {
                SecretName = $"es/{config.Name}/db-master",
            }),
            DatabaseName = DatabaseName,
            MultiAz = config.DbMultiAz,
            AllocatedStorage = config.DbAllocatedStorageGb,
            MaxAllocatedStorage = config.DbMaxAllocatedStorageGb,
            StorageType = StorageType.GP3,
            StorageEncrypted = true,
            PubliclyAccessible = false,
            BackupRetention = Duration.Days(config.DbBackupRetentionDays),
            PreferredBackupWindow = "18:00-19:00",               // 02:00–03:00 Singapore time
            PreferredMaintenanceWindow = "sun:19:30-sun:20:30",  // Monday 03:30–04:30 Singapore time
            DeletionProtection = config.IsProduction,
            RemovalPolicy = config.IsProduction ? RemovalPolicy.RETAIN : RemovalPolicy.SNAPSHOT,
            ParameterGroup = parameters,
            AutoMinorVersionUpgrade = true,
            EnablePerformanceInsights = true,
            PerformanceInsightRetention = config.DbAdvancedInsights
                ? PerformanceInsightRetention.MONTHS_15
                : PerformanceInsightRetention.DEFAULT,
            CloudwatchLogsExports = new[] { "postgresql" },
            CopyTagsToSnapshot = true,
        });
        Database.Node.AddDependency(logGroup);

        if (config.DbAdvancedInsights)
        {
            // shortcut: set through the CloudFormation property because the L2 construct may not expose it; verify at first synth.
            ((CfnDBInstance)Database.Node.DefaultChild!).AddPropertyOverride("DatabaseInsightsMode", "advanced");
        }

        AppUserSecret = UserSecret("DbAppUser", config, "es_app", "app", removal);
        ReadOnlyUserSecret = UserSecret("DbReadOnlyUser", config, "es_readonly", "readonly", removal);

        Database.Connections.AllowDefaultPortFrom(Bastion, "bastion psql tunnel");

        if (config.DbProxy)
        {
            var proxySecurityGroup = new SecurityGroup(this, "ProxySg", new SecurityGroupProps
            {
                Vpc = vpc,
                Description = $"ExtraSpace {config.Name} RDS Proxy",
                AllowAllOutbound = false,
            });

            Proxy = Database.AddProxy("Proxy", new DatabaseProxyOptions
            {
                DbProxyName = $"es-{config.Name}-proxy",
                Secrets = new[] { AppUserSecret },
                Vpc = vpc,
                VpcSubnets = new SubnetSelection { SubnetType = SubnetType.PRIVATE_ISOLATED },
                SecurityGroups = new ISecurityGroup[] { proxySecurityGroup },
                RequireTLS = true,
                IamAuth = false,
            });

            Database.Connections.AllowDefaultPortFrom(proxySecurityGroup, "RDS Proxy to PostgreSQL");
            _ = new CfnOutput(this, "ProxyEndpoint", new CfnOutputProps { Value = Proxy.Endpoint });
        }

        _ = new CfnOutput(this, "DbEndpoint", new CfnOutputProps { Value = Database.DbInstanceEndpointAddress });
        _ = new CfnOutput(this, "DbMasterSecretName", new CfnOutputProps { Value = $"es/{config.Name}/db-master" });
        _ = new CfnOutput(this, "BastionInstanceId", new CfnOutputProps { Value = Bastion.InstanceId });
    }

    // The PostgreSQL role itself is created by hand with this password (aws-setup-guide B5).
    private Secret UserSecret(string id, EnvConfig config, string username, string suffix, RemovalPolicy removal) =>
        new(this, id, new SecretProps
        {
            SecretName = $"es/{config.Name}/db-{suffix}",
            Description = $"PostgreSQL user {username} ({config.Name})",
            GenerateSecretString = new SecretStringGenerator
            {
                SecretStringTemplate = $$"""{"username":"{{username}}"}""",
                GenerateStringKey = "password",
                ExcludePunctuation = true,
                PasswordLength = 32,
            },
            RemovalPolicy = removal,
        });
}
