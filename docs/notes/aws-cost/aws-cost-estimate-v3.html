Monthly AWS cost for the new platform

The new platform is one application that serves Singapore and Malaysia together: the mobile app API, the staff admin, BizPlus, Cowork and the background jobs, with a PostgreSQL database. It runs on AWS in Singapore, with a production environment and a staging environment for testing. It is sized on the real usage of today's systems in both countries. Prices are in US dollars, before tax.

Monthly budget to approve ≈ US$500 launch size plus a 15% buffer for unknowns
Launch cost US$437 production US$317 + staging US$121
Expected after tuning US$270–330 after 1–2 months of real measurements

At launch size the yearly cost is about US$5,250, and the yearly budget with the buffer is about US$6,040. Running a separate copy of production per country, as the current system does, would roughly double the production cost.

Why we launch larger than today's usage needs

Today's traffic is small (see the next section), but the new BizPlus and Cowork features have no usage history yet, and memory is the first thing to run short on small servers. So production starts one size up, with room to spare. Once the platform has run for 1–2 months, we size it to the measured load. Making servers smaller is a simple change; the database needs a short restart.

The 15% buffer covers what this estimate cannot know yet: log volume, internet data transfer, extra database CPU in busy periods, and the real load of BizPlus and Cowork.

Not included

  • Tax on the AWS invoice.
  • An AWS Support plan, if one is wanted.
  • Domain names and DNS hosting.
  • Third-party fees: SiteLink, Stripe transaction fees, Apple and Google developer accounts, and GitHub if the code repository becomes private.
  • Staff sign-in uses the company's Microsoft 365 accounts. No extra licence is expected; to be confirmed with IT.
  • Hosting Malaysian data in Singapore is assumed to be acceptable under Malaysia's data protection rules. To be confirmed by the business.

Assumptions and sources

  • One platform serves both countries; each site carries its own currency and time zone. Region Singapore (ap-southeast-1). On-demand prices. Everything runs 24 hours a day, counted as 730 hours per month.
  • Usage as measured on today's systems; BizPlus and Cowork are covered by the launch size and the 15% buffer. The final bill follows real usage.
  • All unit prices come from AWS's public price list for Singapore, versions published between 11 September and 8 October 2026, read on 9 October 2026. AWS may change prices.
