Monthly AWS cost for the new platform

The new platform is one application that serves Singapore and Malaysia together: the mobile app API, the staff admin, BizPlus, Cowork and the background jobs, with a PostgreSQL database. It runs on AWS in Singapore, with a production environment and a staging environment for testing. This version is sized for performance and resilience within a budget of US$1,000–1,500 a month. Prices are in US dollars, before tax.

Monthly budget to approve ≈ US$1,170 monthly cost plus a 15% buffer for unknowns

The yearly cost is about US$12,230, and the yearly budget with the buffer is about US$14,065. The budget leaves about US$330 a month of room below the US$1,500 limit for growth.

What the larger budget buys

Today's traffic is small (see the usage section), so the extra budget goes where it makes the platform faster under load and keeps it running when a part fails, not into idle capacity.

UpgradeWhat it gives
Database on a dedicated-CPU serverdb.t4g.medium (4 GB) → db.m8g.large (8 GB, latest Graviton4)Full CPU at all times, with no burst credits that can run out in busy periods. The whole database fits in memory many times over, so reads come from memory.
Larger app servers, with auto-scaling2 × 1 vCPU / 2 GB → 2 × 2 vCPU / 4 GB, up to 4 at busy timesFaster responses under load. Extra servers start automatically when traffic rises and stop when it falls.
Separate server for background jobsnew: 1 × 1 vCPU / 2 GBBilling runs, SiteLink syncs and email sending no longer compete with app and admin requests.
Shared cachenew: ElastiCache Valkey, 2 nodes with failoverSiteLink is the slowest part of every self-storage screen. Caching unit and price data makes those screens fast and reduces calls to SiteLink.
Database connection proxynew: RDS ProxyKeeps database connections ready as servers scale up and down, and cuts the pause during a database failover.
Second NAT gateway1 → 2, one per data centreCalls to SiteLink, Stripe and email keep working if one data centre fails.
Web application firewallnew: AWS WAF with managed rules and rate limitsBlocks common attacks and floods of requests before they reach the app.
Database performance monitoringnew: Database Insights (advanced), 15 months of historyShows which queries are slow, so the team can fix them early.
Longer backups and a realistic staging14 → 35 days of backups; staging database db.t4g.micro → db.t4g.mediumMore time to recover data, and staging is large enough for real load tests before each release.

More hardware cannot make SiteLink itself answer faster; its response time is outside our control. The cache is what hides it from the user.

Not included

  • Tax on the AWS invoice.
  • An AWS Support plan, if one is wanted.
  • Domain names and DNS hosting.
  • Third-party fees: SiteLink, Stripe transaction fees, Apple and Google developer accounts, and GitHub if the code repository becomes private.
  • Staff sign-in uses the company's Microsoft 365 accounts. No extra licence is expected; to be confirmed with IT.
  • Hosting Malaysian data in Singapore is assumed to be acceptable under Malaysia's data protection rules. To be confirmed by the business.

Assumptions and sources

  • One platform serves both countries; each site carries its own currency and time zone. Region Singapore (ap-southeast-1). On-demand prices. Everything runs 24 hours a day, counted as 730 hours per month.
  • Usage as measured on today's systems; BizPlus and Cowork are covered by the larger servers and the 15% buffer. The final bill follows real usage.
  • Log volume, firewall request count and Container Insights metrics are estimates; the 15% buffer covers a difference. The next database size is priced from the previous Graviton generation.
  • All unit prices come from AWS's public price list for Singapore, versions published between 11 September and 8 October 2026, read on 9–10 October 2026. AWS may change prices.
